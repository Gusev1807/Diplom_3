# Diplom_3

Тесты проверяют:

Вход в аккаунт через разные кнопки;

Регистрацию нового пользователя;

Проверку работы раздела Конструктор и переключения между вкладками ингредиентов: Булки, Соусы, Начинки.

Структура проекта

pages/ — классы страниц (Page Object Model):

MainPage — главная страница приложения;

RegisterPage — страница регистрации;

LoginPage — страница входа в аккаунт;

ConstructorPage — страница конструктора ингредиентов.

tests/ — тестовые классы:

LoginTest — проверка входа в аккаунт;

RegisterTest — проверка регистрации;

ConstructorTest — проверка переключения вкладок конструктора.

Используемые технологии

Java 11

Selenium WebDriver 4.9.1

JUnit 4

Allure 2 (для отчетов)

ChromeDriver
